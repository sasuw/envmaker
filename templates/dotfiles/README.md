# dotfiles

Dotfiles managed with [envmaker](https://github.com/sasuw/envmaker).
envmaker keeps its configuration and state in directories named
`dotfiletracker`.

See [How to add and apply dotfiles](docs/getting_started.md) for setup.
That guide also covers registering this tree as a generic or personal overlay
source. Later sources win whole target files; a complete personal fork overrides
every matching generic file, including unchanged copies.
